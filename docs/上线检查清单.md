# 上线检查清单

## 必须完成

- [ ] 域名已解析到服务器，80/443 可访问
- [ ] `.env` 中 `POSTGRES_PASSWORD`、`SYNC_SECRET`、`CONFIG_ENCRYPTION_KEY`、`ADMIN_KEY` 均为独立随机值，未提交 GitHub
- [ ] PostgreSQL 未映射公网端口
- [ ] `docker compose ps` 中三个服务均为 healthy/running
- [ ] `/api/health` 返回 `status: ok`
- [ ] 学号登录后，数据库 `users.id` 为哈希值而非原始学号
- [ ] 两台设备能同步进度、收藏、笔记和设置
- [ ] 邮箱验证码已用真实 SMTP 验收；若未配置，页面不得宣传邮箱可用
- [ ] 评论发布、敏感词待审、举报、删除、管理员通过/隐藏/禁言均已验收
- [ ] 首页左下角“自定义AI”能进入 `/custom-ai`，读取并保存所选厂商；“知微”完成至少一道演示题解析与一次连续追问
- [ ] `AI_DAILY_LIMIT` 已设置，并在所选 API 服务商后台打开费用告警
- [ ] 用户可导出学习记录并重新导入
- [ ] 版权页、医学声明与 `QUESTION_SOURCES.md` 已核对
- [ ] 手动备份成功，并至少完成一次测试恢复
- [ ] Ubuntu 自动安全更新、每日备份和日志轮转已启用

## 建议完成

- [ ] GitHub 仓库启用分支保护和 Actions 环境审批
- [ ] 部署 SSH 密钥只允许必要权限
- [ ] 设置服务器磁盘、内存、证书到期和容器异常告警
- [ ] 制定评论处理时限与版权投诉联系人
- [ ] 每次发布创建 Git 标签并记录变更
