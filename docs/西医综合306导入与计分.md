# 西医综合 306 导入与计分

本项目根据用户提供的 1994、2023、2024、2025 年西医综合真题卷面实现年份感知的专项结构化。此模式只整理文件明确包含的题目与答案，不调用医学常识猜测缺失答案。

## 试卷结构

| 题号 | 题型 | 每题分值 | 小计 |
| --- | --- | ---: | ---: |
| 1–40 | A 型单选 | 1.5 | 60 |
| 41–115 | A 型单选 | 2 | 150 |
| 116–135 | B 型共用备选项单选 | 1.5 | 30 |
| 136–165 | X 型多选 | 2 | 60 |
| 合计 | 165 题 |  | 300 |

旧卷若出现 C 型题，系统按原卷分区保留。C 型题的 A/B 是两条来源陈述，答案编码为：A=仅 A 正确、B=仅 B 正确、C=两者均正确、D=两者均不正确；它仍是单选判定题，不计作 X 型多选。旧卷分值以原卷为准，系统不会套用现代 300 分规则。

## 导入规则

- 文件名或开头文字包含“西医综合”“西综”“临床医学综合能力（西医）”或 306 时启用专项模式。
- `年份 + N + 题号 + 题型`（例如 `2024N1A.`）会作为题目头处理，不会再误识别为第一个 A 选项。
- B 型题保留共用备选项组，并把同组备选项关联到每一道小题。
- C 型题保留两条来源陈述、四种判定选项和共用组信息。
- X 型题必须完全匹配文件提供的正确选项；多选或少选均按错误处理。
- 题目按原题号去重和排序，分值由原题号确定。
- AI 输出采用逐题独立的 NDJSON。系统还能从外层 JSON 数组局部损坏的响应中恢复其余完整题目。
- 长文件优先按 PDF 页面与可见原题号切片，并限制每片题数，避免模型在约 60 题处截断。
- 没有答案的完整题目会进入测试模式；之后可导入答案卷按原题号一键核对。

## 306 标准化工作台

从“导入题库”进入“西综 306 标准化工作台”：

1. 选择题目原卷（必选），可使用 PDF、OCR 后的 DOCX 或旧版 DOC。
2. 如有独立答案/解析卷，可一并选择；没有答案时先生成测试题库。
3. 系统先在浏览器提取文字与 OCR。若原卷已经具备完整题干、选项和题后明确答案，则直接在本地按年份、题号和 A/B/C/X 分区确定性整理；只有非标准结构才交给已配置的 AI 分段结构化。
4. 完成后显示年份、卷型、有效题数、各题型数量、答案覆盖率与缺失原题号。
5. 可直接保存到“我的题库”，也可导出 `avecove-western-306` 标准 JSON 供复核或二次处理。

## 风险提示

扫描 PDF 的文字质量取决于原始分辨率、倾斜、双栏排版和水印。对于纯图片 2025 卷，优先使用系统 OCR 后的 DOCX，速度和题号完整性通常更好。完成导入后，应抽查 A、B、C、X 分区的题号、共用选项、答案和总分；本功能只用于学习训练，不替代官方试卷、教材或考试机构说明。
