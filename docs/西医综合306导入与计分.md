# 西医综合 306 导入与计分

本项目根据用户提供的 2023、2025 年西医综合真题卷面实现专项结构化。此模式只整理文件明确包含的题目与答案，不调用医学常识猜测缺失答案。

## 试卷结构

| 题号 | 题型 | 每题分值 | 小计 |
| --- | --- | ---: | ---: |
| 1–40 | A 型单选 | 1.5 | 60 |
| 41–115 | A 型单选 | 2 | 150 |
| 116–135 | B 型共用备选项单选 | 1.5 | 30 |
| 136–165 | X 型多选 | 2 | 60 |
| 合计 | 165 题 |  | 300 |

## 导入规则

- 文件名或开头文字包含“西医综合”“西综”“临床医学综合能力（西医）”或 306 时启用专项模式。
- B 型题保留共用备选项组，并把同组备选项关联到每一道小题。
- X 型题必须完全匹配文件提供的正确选项；多选或少选均按错误处理。
- 题目按原题号去重和排序，分值由原题号确定。
- AI 输出采用逐题独立的 NDJSON。系统还能从外层 JSON 数组局部损坏的响应中恢复其余完整题目。
- 长文件会按片段处理，并把答案表、参考答案或解析区作为关联参考；无法确认答案的题目不会写入题库。

## 风险提示

扫描 PDF 的文字质量取决于原始分辨率、倾斜、双栏排版和水印。完成导入后，应抽查 A、B、X 三段的题号、共用选项、答案和总分；本功能只用于学习训练，不替代官方试卷、教材或考试机构说明。
