## 视频简介

AveCove Elapse 是一个面向医学学习者的本地优先、自托管题库系统。它可以把 Word、PDF、扫描版试卷以及独立答案卷整理成可练习的结构化题库，并提供题库分组、全局搜索、错题复盘、收藏笔记、AI 学习区、多端同步与考研西医综合 306 专用工作台。

本视频以 1.0.0 版本为准，完整展示从导入文件、检查识别结果到刷题和复盘的实际流程，也会说明当前限制、隐私边界和后续开发重点。项目公开不代表题库文件可以被随意传播；导入与分享内容时请遵守原始资料的版权和使用许可。

## 录制前准备

- 使用一套公开、已获授权或自行制作的演示题库，避免画面中出现未经授权的整份试卷。
- 准备一份 DOCX、一份文字型 PDF、一份扫描型 PDF，以及一组题目卷与答案卷。
- 在浏览器中预先登录同步账户，并准备一个没有个人隐私的演示学号和邮箱。
- 在“自定义 AI”中准备可用的模型配置；录屏前遮挡 API Key。
- 清空无关浏览器标签、通知、下载列表和剪贴板历史。
- 关闭或隐藏服务器面板、终端中的密码、授权码、域名邮箱设置。
- 准备一个桌面浏览器窗口和一个手机或 iPad 画面，用于展示响应式布局与同步。
- 录制前完成一次题库备份或导出，避免演示中的删除、重置操作影响真实数据。

## 功能优势清单

### 医学题库导入

- Word、PDF、扫描 PDF 和多文件批量导入。
- 普通解析、OCR、AI 结构化和人工审计组合。
- 题目卷与答案卷可分开导入并关联。
- 缺答案题目可先进入测试模式，之后补答案。
- 答案、解析和题号来源可追溯。

### 题库管理

- 重命名、简介、删除、分享、进度重置。
- 全局搜索与关键词高亮。
- AI 辅助分组和组级错题复盘。
- 本地浏览器存储与可选服务器同步。

### 刷题与复盘

- 顺序练习、随机 20 题、模拟 100 题。
- 单选、多选、判断题。
- 错题、收藏、笔记、标签、来源追踪。
- 原文件解析与 AI 学习解释并存。
- 移动端、iPad 与桌面端分别优化。

### 西综 306

- 现代 165 题 / 300 分结构。
- A、B、X 型题与旧制 C 型题。
- 跨页拼接、答案关联、缺题审计。
- 首次作答计分锁定。
- 标准 JSON 导出和题库保存。

### 隐私与自托管

- 原始文件默认留在浏览器本地处理。
- AI 厂商由用户自行配置。
- 支持 Docker 部署到自己的服务器。
- 学号使用不可逆标识，多端同步无需手机号或微信。

## 已知限制与待处理问题

- 扫描质量差、双栏排版、跨页选项和水印会降低 OCR 与题目拼接准确率。
- 复杂答案表、混合题号和非标准符号仍需人工抽查。
- 大文件 AI 结构化可能受模型输出长度、JSON 完整性和接口超时影响。
- AI 生成解释可能不准确或过时，不用于医疗建议或临床决策。
- `.doc` 兼容依赖服务端转换工具；建议优先使用 `.docx`。
- 英语模块在 1.0.0 中只保留演示交互与本地 Test Library，完整生产能力暂缓。
- 评论区、社区审核和更精细的权限体系仍处于后续规划。
- 同步服务上线前仍应配置备份、速率限制、邮件可达率监控和数据库恢复演练。

## 演示风险与备用方案

- AI 接口不可用：切换到已提前导入的演示题库，展示导入结果和审计页。
- OCR 时间过长：使用预先生成的 OCR 文本或 DOCX 继续演示。
- 邮件验证码延迟：准备已登录设备；说明应检查垃圾邮件与垃圾箱。
- 同步网络不稳定：先展示本地功能，再用录制好的短画面补充跨设备效果。
- 题库版权不确定：只展示少量自制题或经过授权的样例。
- 删除或重置误操作：使用演示账户并在录制前导出备份。
