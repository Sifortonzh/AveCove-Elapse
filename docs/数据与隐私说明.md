# 数据与隐私说明

## 浏览器本机保存

- 导入后的题库内容
- 临时答题界面状态
- 学习记录的本机副本

## 开启多端同步后，服务器保存

- 由学号和服务器密钥生成的不可逆同步标识
- 可选邮箱、昵称、学习进度、收藏、笔记和设置
- 评论、点赞、举报、审核状态
- AI 每日请求次数

服务器不会保存原始学号，也不会上传原始 Word/PDF 文件。邮箱不会公开展示；评论区仅展示昵称。

## 用户控制

- 退出登录只清除当前设备会话，本机记录仍保留。
- 导出学习记录会生成 JSON 文件，方便个人备份。
- 注销云端身份会删除该身份的学习记录、评论、点赞和举报。
- 删除浏览器站点数据会清除本机题库与本机记录，但不会自动删除云端身份；应先在同步面板选择注销。

## 不应保存的内容

不要在题库、笔记或评论中写入患者姓名、住院号、联系方式、影像原片等临床隐私。本产品是学习工具，不是医疗数据系统。
