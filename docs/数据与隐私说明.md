# 数据与隐私说明

## 浏览器本机保存

- 导入后的题库内容
- 临时答题界面状态
- 学习记录的本机副本

## 开启多端同步后，服务器保存

- 由学号和服务器密钥生成的不可逆同步标识
- 可选邮箱、昵称、学习进度、收藏、笔记和设置
- 用户选择同步的浏览器解析后中英文题库、英文选择题记录与写作草稿
- 评论、点赞、举报、审核状态
- AI 每日请求次数

服务器不会保存原始学号，也不会保存原始 Word、PDF 或图片文件。登录同步身份后，浏览器会把已经解析成结构化数据的中英文题库和相应学习记录写入个人同步空间，便于其他设备恢复；用户应只同步自己有权使用的内容。新版 `.docx` 与 PDF 在浏览器本机处理；旧版 `.doc` 会临时进入本应用服务器内存以提取文字，原文件不写入磁盘。只有在普通规则识别失败、用户明确选择“用 AI 识别”后，已经提取的文字才会发送给当前配置的 AI 服务商，并可能消耗接口额度。邮箱不会公开展示；评论区仅展示昵称。

## 用户控制

- 退出登录只清除当前设备会话，本机记录仍保留。
- 导出学习记录会生成包含解析后题库与学习状态的 JSON 文件，方便个人备份；请妥善保管并遵守题库版权要求。
- 注销云端身份会删除该身份的学习记录、评论、点赞和举报。
- 删除浏览器站点数据会清除本机题库与本机记录，但不会自动删除云端身份；应先在同步面板选择注销。

## 不应保存的内容

不要在题库、笔记或评论中写入患者姓名、住院号、联系方式、影像原片等临床隐私。本产品是学习工具，不是医疗数据系统。
